# Platform AI daily allowance

Configure a platform key and save a tutor default model on the administrator AI models page. Keys use the existing server-side credential vault and are never returned to learners or administrators. The saved model and connection revision must match. Connection edits update saved policies to the current endpoint and revision and invalidate their previous model verification.

Learners must accept the external-AI disclosure and the provider's current routing consent in Settings → Privacy & consent. They can use platform AI without adding a personal key. Personal enabled keys are tried first and suppress the platform key for the same provider, including pending, invalid, rate-limited, or unreachable personal credentials. Disabled, deleted, or revoked personal keys do not suppress platform routing. Explicit administrator fallback grants keep their existing consent and token/cost limits.

`PLATFORM_AI_DAILY_REQUEST_LIMIT` defaults to 25 and accepts integers from 1 through 1,000,000. One shared per-user allowance is consumed before the first platform provider call, regardless of failover across platform providers. Own-key calls do not consume it. Admitted attempts count even if the provider fails; requests rejected for exhausted quota do not count as admitted usage. Idempotent replay does not consume again. Persistence failures block platform calls with `PLATFORM_AI_QUOTA_UNAVAILABLE`; exhaustion returns HTTP 429 with `PLATFORM_AI_QUOTA_EXCEEDED` and opens the add-key popup.

The allowance resets at midnight UTC using the existing `rate-limiter-flexible` Postgres store and `api_rate_limit` table. No schema migration is needed. The administrator page shows today's admitted platform attempts summed across users, including provider failures. This is an attempt counter, not a count of successful responses or billed tokens. Lowering the configured limit during a day also lowers the cap used in that summary; change it at UTC midnight for consistent daily reporting. Rotating the rate-limit identity HMAC secret changes buckets, as with the existing application limiters.
